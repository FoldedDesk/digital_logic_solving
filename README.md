# 数字电路与数字逻辑解题 Skill

用于大学《数字电路与数字逻辑》作业与习题，覆盖组合逻辑、时序逻辑、波形分析和电路设计。按题型读取参考流程，从识图、列式、列表到验证，支持完整解答、逐步教学和精简作业答案。

## 安装与使用

将 [`skills/digital-logic-solving`](skills/digital-logic-solving) 目录放入 Codex 的 skills 目录（通常为 `~/.codex/skills/`），重新打开 Codex 后调用：

```text
请使用 $digital-logic-solving 解答这道题，给出必要推导、表格或图形，并验证结果。
```

## 内容

- [SKILL.md](skills/digital-logic-solving/SKILL.md)：解题约束、题型路由和验证要求。
- [references](skills/digital-logic-solving/references)：组合逻辑、时序逻辑与波形分析流程。
- [原始工作流](skills/docs/digital-logic-solving-workflow.md)：制作 skill 的来源文档。
