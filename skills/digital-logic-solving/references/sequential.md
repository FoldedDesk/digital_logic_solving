# 时序逻辑分析与设计

## 驱动方程与次态

先确认各存储器件类型、时钟来源、触发沿/透明电平、异步置位/清零的有效电平及优先关系。分别写出各器件的 \(D_i\)、\(J_i,K_i\)、\(T_i\) 或 \(S_i,R_i\)，再代入特性方程。

以下方程适用于相应器件的正常更新条件，且没有有效异步控制覆盖：

| 类型 | 特性方程 | 约束 |
| --- | --- | --- |
| D | \(Q^{+}=D\) | 按器件规定的沿或透明电平更新 |
| JK | \(Q^{+}=J\overline{Q}+\overline{K}Q\) | 边沿触发器在有效沿采样 |
| T | \(Q^{+}=T\oplus Q\) | \(T=1\) 翻转，\(T=0\) 保持 |
| 高电平有效 SR | \(Q^{+}=S+\overline{R}Q\) | 排除 \(S=R=1\)；低电平有效端须按器件功能表处理 |

异步控制有效时，按器件功能表确定状态，不能继续套用正常时钟更新。置位和清零同时有效时，依据题目或器件规定处理；缺少规定时标明非法或不确定，不自行规定优先级。

**同步电路中，所有次态都由同一组现态和该沿采样的输入计算。** 不要先更新某一位，再把更新值代入另一位的驱动方程。异步或脉动电路不直接套用此同步更新规则。

## 状态表、状态图和功能

1. 声明状态变量的排列顺序和编码，区分现态、次态以及表中输出的时刻。
2. 列出“现态、输入、驱动输入、次态、输出”。在题目要求的范围内覆盖状态和输入组合，标注全部未使用状态及其处理方式。
3. 逐行代入驱动方程和特性方程；不要凭计数规律补填尚未验证的行。
4. Moore 输出写成 \(Y=g(Q)\)，Mealy 输出写成 \(Y=g(Q,X)\)。需要更新后输出时，明确使用次态与相应时刻输入重算。
5. 按状态表画有向图。Moore 输出标在状态上，Mealy 输出标在转移边上；边标注输入条件，表中的每个转换与图中的边双向对应。
6. 从状态循环和输出推导功能：计数模数和顺序、移位方向、检测序列及重叠能力，或输出分频关系。分频需检查相应输出的实际周期。

\(n\) 个二值状态位有 \(2^n\) 种编码。正常工作循环以外的编码应标明，不能无说明地删除或自动记成无关项。

## 无效状态和自启动

“无效状态”指未用于正常工作流程的状态编码，不代表物理上不会出现。

1. 确定正常状态集合，列出其余需要考虑的编码。
2. 使用**最终实际驱动方程**计算每个无效状态的次态；沿转移继续追踪到正常集合，或找到无效状态闭环。
3. 无输入的计数器等电路，只有全部需考虑的无效状态均能在有限次正常时钟后进入正常集合，才判定能自启动。
4. 输入控制的电路应说明恢复所需的输入条件。区分任意允许输入下均能恢复、仅特定输入序列下能恢复，以及存在无法恢复路径的情况。
5. 单独说明异步复位等外部恢复机制。外部复位能够恢复，不能证明仅靠正常时钟即可自启动。

若无效状态在设计化简中获准用作无关项，仍须在最终实现上重新分析其转移；无关项不保证实现后的恢复行为。

## 异步时序与竞争

- 没有统一有效沿时，按实际使能、局部时钟和反馈关系分析。稳定状态需满足在当前输入下状态不再变化；沿反馈变化追踪到新的稳定状态。
- 脉动计数器等电路逐个跟踪局部时钟事件及触发沿，不把传播过程中的状态位视作同步更新。
- 多个状态变量在一次转换中改变时，比较不同变化顺序。若顺序会改变最终稳定状态，则存在临界竞争；给出具体路径与可能的错误状态。
- 按题目规定的输入变化及延迟假设分析；信息不足时不编造唯一传播顺序。需要消除竞争时再考虑状态编码或结构修改。
- 不把同步电路在一个时钟沿更新多位直接称为异步竞争。时钟偏斜、建立时间和保持时间问题应按实际时序条件另行分析。

输出组合逻辑的冒险分析方法见[组合逻辑参考](combinational.md#竞争与冒险)，只在适用时读取。

## 按要求设计

1. 从功能要求确定输入输出、初态、状态集合及转换条件。序列检测题明确是否允许重叠检测，选择符合题意的 Moore 或 Mealy 模型。
2. 按要求编码，采用指定触发器；题目允许选择时说明选择依据。
3. 先列目标现态/次态表，再使用相应**激励表**求驱动输入，化简驱动方程和输出方程。不要把特性方程直接当成各输入端的激励方程。
4. 按指定门和触发器画最终电路，标明时钟、复位、有效电平、各驱动端及输出。
5. 从最终方程重新生成状态转移，核对所有规定输入下的功能、输出和器件约束；按题目要求检查无效状态、自启动及适用的竞争冒险问题。
