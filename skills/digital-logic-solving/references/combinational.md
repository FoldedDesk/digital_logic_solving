# 组合逻辑分析与设计

## 分析电路

1. 确定输入和输出的逻辑含义、有效电平，以及使能/选通条件。
2. 按信号流向给中间节点命名，逐级写出逻辑门输出，再代入得到最终函数。核对每个反相泡和低电平有效端。
3. 声明输入变量顺序。对 \(n\) 个独立二值输入，完整真值表应包含 \(2^n\) 种组合，通常按二进制顺序排列。
4. 逐行计算输出；有约束时标出禁止出现的组合，说明哪些组合获准作为无关项。
5. 按题目要求用布尔代数或卡诺图化简，并检查化简式在全部规定输入上与原式等价。
6. 根据表达式和真值表描述功能，如译码、选择、校验、加法或比较；不要仅凭电路外观命名功能。

多输出电路逐个推导输出，检查公共中间节点是否一致。低电平有效输出需说明其被置为 0 时代表的功能。

## 卡诺图

- 先标变量及位权，行列按格雷码排列，如 `00、01、11、10`，明确最小项编号与坐标的对应关系。
- 按原函数和约束填入 0、1 和无关项。无关项可参与扩大圈组，也可不用，不必全部覆盖。
- 求最简与或式时圈 1，求最简或与式时圈 0。圈组为 \(1,2,4,8,\ldots\) 格的矩形，允许跨边界和重叠，不允许包含相反的确定值。
- 覆盖全部必须覆盖的 1 或 0。逐圈说明保留哪些不变变量，以及它们对应的积项或和项。
- 检查覆盖完整性和冗余，随后回代全部规定输入；不能只验证参与圈选的几格。

## 按要求设计

1. 将文字要求转成输入输出含义、有效电平和真值表。约束或无关项必须有题意依据。
2. 写出逻辑函数，按指定目标化简；多输出题按要求考虑公共项。
3. 将化简结果变换为指定门电路形式。与非门或或非门实现需要完成相应的德摩根变换、反相和极性检查，普通与或式不是最终实现。
4. 给出电路图或明确的节点连线表，标注输入、输出、门类型、反相和使能端。
5. 从最终实现重新求函数，在全部规定输入上验证其行为和器件限制。

## 竞争与冒险

题目要求分析，或电路行为确实依赖毛刺时，再进行此项检查。

- 静态冒险关注输入变化前后理论值相同、实际却可能出现短暂反转的输出；区分静态 0 冒险、静态 1 冒险和动态冒险。
- 沿不同传播路径分析延迟。表达式出现某变量及其反变量，本身不足以断言必有冒险。
- 对两级与或结构，在单输入变化的静态 1 冒险分析中，检查相邻的 1 是否有共同圈组/积项覆盖；缺少覆盖时可增加共识项。两级或与结构可对应检查相邻的 0。
- 增加冗余覆盖项后，验证逻辑函数不变，说明其针对的转换。不要把静态冒险的覆盖检查当成任意多输入变化或动态冒险的通用证明。
- 未给传播延迟时，可判断结构上是否可能出现毛刺，不编造具体毛刺宽度。

普通组合逻辑题不附加“自启动”检查。
